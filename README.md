# 游园灯 · 教学展示版

本仓库是 **Carousel Lamp · 旋转木马相片灯**（作者：咕噜蛋Daria）的**修改版本**，仅用于非商业的课堂教学展示。原作的署名与许可说明见网站最后一页（`credits.html`）和 [LICENSE](LICENSE)。

## 与原作相比的修改

- 改为纯静态网页（HTML + CSS + JS），不需要服务器和构建步骤，可以直接用 GitHub Pages 托管。
- 旋转木马固定为夜晚、旋转、起风的状态，删去了对应的三个按钮。
- 封面不再显示署名，署名与致谢单独放在最后一页。
- 新增背景音乐与动态歌词：可以自选一首歌和歌词，翻页时音乐不中断；歌词以大号粗体逐字浮现，正在唱的字发蓝光，下方配译文；也可以打开全屏的“沉浸式歌词”。
- 新增“查看我们走过的地图”：一本摊开的 3D 册子，整体是江南水乡的风格。右页是水墨示意地图，可以在上面放置地点并配上照片；左页“草木记”按顺序为每个地方夹一片植物标本（前 6 处）。四川、河北两处出生地用红灯笼着重标出。从旋转木马页进入时有一段开场：书桌上的相机包鼓一下、翻盖弹开，相机从包里弹出来，举到眼前“咔嚓”拍下一张，再收回包里、翻盖合上，接着册子翻开，露出地图（点任意处可跳过；系统开启“减少动态效果”时不播放）。竖屏手机和平板上册子旁边放不下相机包，开场时包会放在合着的册子上，拍完跳到画面外，册子再翻开。书桌上还有几件立体的小摆件：冒着热气的青花茶杯、一小盆多肉、两卷纸胶带和一只 135 胶卷，它们有真的阴影，合上册子转动视角时能看出前后。看完可以点工具栏的「合上册子」：册子合上，镜头退回到书桌照片的视角。这时按住拖动可以换个角度看看书桌（左右、上下各能转一些，滚轮可以拉近拉远）：书桌照片被“投”回了三维里，桌面和后面的书架有前后的立体感，转得太多照片会穿帮，所以角度做了限制。点「翻开册子」或直接点桌上的册子即可再次打开；点桌上的相机包，相机会再弹出来拍一张。

## 页面顺序

`carousel.html`（旋转木马）→ `map.html`（我们走过的地图）→ `elephants.html`（跟着小象走一走）→ `qianfu.html`（潜伏手账）→ `credits.html`（五线谱蛋糕：小蔚，要幸福！）

`index.html` 是外壳页：五页都在它里面的画框中切换，播放器和歌词也在这一层，所以翻页时音乐不会停。直接打开某一页（例如 `map.html`）会自动跳回 `index.html#map`。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，把本文件夹里的**全部内容**（包括 `.nojekyll`）上传到仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. Source 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等一两分钟，页面顶部会显示网址，形如 `https://你的用户名.github.io/仓库名/`。

## 在自己电脑上预览

浏览器不允许直接双击打开使用模块脚本的网页，需要起一个本地服务器。在本文件夹中打开终端：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 地图页开场为什么不卡了

- 开场前先等所有图片读完，把贴图传给显卡、把着色器编译好（`js/map-scene.js` 里的 `prepare`），这时三维画面还是透明的；准备好以后画面淡入，相机才开始动。以前这些事情挤在开场动画里做，尤其是 3200×2134 的书页大贴图，所以会卡一下。
- 两盏红灯笼的光源一直留在场景里，书合上时只把亮度调成 0。以前是开场结束时才出现，光源数目一变，所有材质都要重新编译。
- 以前开场期间整页会往右偏 5%（地图页借用了 `intro` 这个样式名，和首页标题的样式撞了），结束时再跳回来，“点击任意处跳过”也点不动。现在改叫 `opening`。

## 关于 Three.js 和网络

3D 渲染使用 Three.js 0.185.1，页面会依次尝试从 jsDelivr、npmmirror、unpkg 加载，哪个最快用哪个。

如果上课的网络环境访问这些 CDN 不稳定，可以把 Three.js 放进仓库：从 npm 下载 `three@0.185.1` 的压缩包，把其中的 `build` 和 `examples` 两个文件夹复制到 `vendor/three/` 下（即 `vendor/three/build/three.module.js` 存在），页面会优先使用本地文件。（旧版 `js/boot.js` 给浏览器的是相对路径，浏览器不认，这个用法其实一直没生效；现在已经改成完整网址。）

## 地图页的几点说明

- 右页是**示意图**：只画了江河、湖泊、海岸和山势，位置是大致的，没有画任何行政区界或国界线，公开发布时可以避免“问题地图”的风险。
- 两个出生地默认放在成都和石家庄。点红灯笼 →「移动位置」可以挪到具体的城市，「编辑」可以改名称、放一张老照片。
- 「更换地图」可以把右页换成一张真实地图的截图，左页标本不受影响。

## 跟着小象走一走

- 在地图页底下点「跟着小象走一走」（或右上角「下一页」）进入。画面上一直飘着雪。八只小象绕着大树一圈圈地走，每只用鼻子拉着前面那只的尾巴；走到树后面时会被树干挡住。
- 点一只小象，会弹出它的日记：横线纸上的手写字，一个字一个字写出来，下面夹着一张风景照。每只小象有两篇，可以翻前一篇、后一篇；按 Esc 或点空白处合上。
- 系统开启“减少动态效果”时，小象站着不动，日记直接显示全文。
- 日记内容都在 `js/elephant-diaries.js`，直接改文字即可。手写字体只收了日记里用到的字，**改了日记以后如果出现新字，新字会用系统楷体代替**；想让新字也是手写体，需要用 `pyftsubset` 从龙藏体（Long Cang）重新生成 `assets/fonts/longcang-diary.woff2`。
- 日记下面的风景是用程序画的（`js/diary-scenes.js`，十种可选）。想换成真实照片：把照片放进 `assets/diary/`，再把那篇日记的 `photo` 改成例如 `'assets/diary/fog.jpg'`。
- 背景用的是大树与小象的插画：`assets/grove-bg.jpg` 是去掉小象后的画面，`assets/grove-trunk.png` 是单独切出来的树干和树根（用来挡住走到树后的小象）。**这幅插画请在致谢页补上作者署名**（`credits.html` 里有一行预留，删掉 `hidden` 即可显示）。

## 潜伏手账

- 在小象页点小象右边的小唱片机（外面绕着一圈字“我和你一起爱左蓝”），或右上角「下一页」进入。
- 画面是一间三维的书房：深绿墙纸、窗外的月亮、日历、挂钟、书架和门；书桌上是绿灯罩台灯、收音机、钢笔，桌上放着一本白色线圈手账，封面是一张手写的拼贴。手账合着的时候，按住拖动可以环顾四周，滚轮可以拉近拉远；翻开手账时镜头会先转回正面。
- 书房、书桌、台灯和收音机都画在一块 WebGL 画布上（`js/study-gl.js`，不依赖任何库、也不用联网）：绿灯罩台灯是立体模型（车削出来的铜底座、弯杆、玻璃灯罩、拉链），台灯本身就是光源，桌上的那圈暖光和书桌、钢笔、收音机的影子都是它照出来的；铜件和玻璃灯罩有反光。书桌是带两个抽屉柜的老式写字台，桌面铺墨绿皮面桌垫。点画面上的台灯或工具栏的按钮都能开关灯。画面只在镜头移动或开关灯时才重画，平时不占资源。手账本仍是网页元素，叠在画布上面，镜头和画布完全对齐。
- 环顾时左右最多转 70°（再转台灯就会挡到手账前面）。不支持 WebGL2 的浏览器只显示深色背景，手账照常能用。
- 手账有厚度：三条边是一层层的纸边，底下有牛皮纸封底，书脊上是 17 个白色螺旋线圈，书页里夹着一根红丝带；右页别着回形针，人物关系页贴着纸胶带。
- 底部工具栏三个操作：「关掉台灯 / 打开台灯」（也可以直接点台灯或拉绳），「打开手账 / 合上手账」（也可以点封面；按 Esc 合上），翻开后「往前翻 / 往后翻」（也可以用方向键或在本子上左右滑动）。
- 翻开先是牛皮纸内封和白色扉页（右边探出一个灰色索引签），扉页上用黑色相角贴着剧组全家福；往后翻是《深海》拼贴页，再往后左边是左蓝海报、左蓝的单人旧照和一张写着一段话的旧照片，右边是人物关系图。合照、剧照、歌词页、海报、旧照片都能点开看大图，旁边是人物说明；人物关系图上的名字也能点。横向的照片（合照、左蓝旧照）在大图里是照片在上、说明在下。
- **人物关系页的指纹**：关系图后面藏着一枚由台词拼成的指纹，开始几乎看不见。每点开一个人的说明（包括在大图里用「上一位 / 下一位」翻到的），关掉大图回到这一页时，指纹就从中心往外显出朝向这个人的那一块；点中间的余则成，显出指纹中心。看过的人名字条上会按一个红指印，左下角显示“指纹比对 n / 6”。六个人都看过以后指纹完整，盖上“已解密”的章，点指纹可以看大图；在这之前，大图里也翻不到它。刷新页面会重新开始。指纹的位置、大小、中心在 `js/qianfu-data.js` 的 `PRINT` 里；每一块的范围是按 `CHART` 里各人的位置自动算的，挪动名字以后扇形会跟着变。
- **人物说明和照片配谁**都在 `js/qianfu-data.js`：`PEOPLE` 是人物介绍（`actor` 留空就不显示扮演者），`PHOTOS` 是每张图配哪些人物，`CHART` 是关系图上名字的位置和连线文字。左页三张剧照目前按拼贴文字配成余则成和翠平，如果照片里是别人，改对应的 `people` 即可。
- 图片在 `assets/qianfu/`：`group.jpg` 是剧组全家福（把拍歪的照片摆正，再用两张局部特写对齐融合，人脸更清楚）；`zuolan-photo.jpg` 是左蓝的单人旧照；`fingerprint.jpg` 是指纹原图（看大图用），`fingerprint-ink.png` 是去掉白底、能印在牛皮纸上的版本；`page-left.jpg`、`page-right.jpg` 是把拼贴照片拉平后的左右两页（先放大两倍、去噪、再锐化，字比原照片清楚）；`still-1~3.jpg` 是从左页裁出的剧照（原图很小，已经尽量清晰化）；`zuolan.jpg` 是海报；`cover.jpg` 是封面；`inner-kraft.jpg`、`inner-white.jpg` 是从线圈本照片里裁出的牛皮纸内封和白色扉页；`note-wanqiu.jpg` 是贴在左蓝旁边的旧照片；`desk-wood.jpg` 是桌面的木纹。
- 左页剧照的可点击区域写在 `qianfu.html` 里三个 `data-photo="still-…"` 按钮的百分比位置上，换图时要一起改。
- **版权提醒**：剧照和海报出自电视剧《潜伏》，课堂本地展示问题不大；公开发布到 GitHub Pages 前请先考虑授权。

## 书桌上的小蛋糕（第 4 页）

- 书桌右后角的双层小蛋糕是三维模型（`js/study-gl.js` 里“右后角的小蛋糕”一段），会被台灯照亮、在桌上投影。蜡烛火苗、“小蔚，生日快乐”字条和点击区域是网页元素（`qianfu.html` 的 `cake-layer`），位置每次随镜头重新计算。
- 点蛋糕或字条：火苗被“吹灭”，冒一缕烟，然后进入第 5 页。翻开手账时蛋糕上的字条和火苗会隐去。

## 五线谱蛋糕（第 5 页）

- `credits.html` + `js/cake-show.js` + `css/cake.css`，用 WebGL2 直接画，不需要联网。七层五线谱绕成蛋糕，谱上的音符都是简谱 1 1 1 6；之后从顶上化成光点（光点里也是 1 和 6），卷成旋转的菱形，收拢后循环。点画面从头再放。
- 时间线、层数、半径都在 `cake-show.js` 开头的 `T`、`R`、`H`、`GAP`。地址后面加 `?t=7`（例如 `credits.html?solo&t=7`）可以停在第 7 秒，方便截图。

## 背景音乐与歌词

- 点右下角（手机上是右上角）的「添加音乐」，选一个音乐文件（MP3、M4A 等），再读取或粘贴歌词，保存即可。
- 歌词支持 LRC 格式：每行开头是时间 `[分:秒.百分秒]`。同一时间写两行，第二行就是译文；也可以写成 `原文 // 译文`。带逐字时间（`<00:12.30>`）的增强 LRC 会精确到每个字；普通 LRC 会在一句之内平均分配。
- 没有时间轴的纯文本歌词也能用，会按歌曲时长平均分配，但不会和演唱对齐。
- 播放器上的按钮：歌词浮层开关、沉浸式歌词（全屏白底，按 Esc 退出、空格暂停）、更换音乐。
- 音乐和歌词同样只保存在当前浏览器里。
- **自动播放**：每次打开网页都会自动播放。浏览器通常不允许没点过页面就出声，这时播放键会轻轻呼吸，点页面任意处（画框里的页面也算）音乐就开始。手动暂停后，这次浏览期间不会再自动播放；下次打开网页照样自动播放。
- 所有页面的歌词浮层大小一致（右上角），在窄屏上的显示规则和以前一样。
- **版权提醒**：多数歌曲和歌词受版权保护。在自己的电脑上课堂播放用“添加音乐”即可；不要把有版权的歌曲文件和歌词放进公开的 GitHub 仓库，那相当于公开传播。
- 如果你有权公开使用某首音乐（例如自己创作或授权可再分发的作品），也可以把它放进仓库：新建 `music/` 文件夹，放入音频和歌词，再写一个 `music/song.json`：

```json
{ "title": "歌名", "artist": "歌手", "audio": "song.mp3", "lyrics": "song.lrc" }
```

  浏览器里没有自己添加过音乐时，页面会自动使用这首。

## 地图页用到的三张图片

都在 `assets/` 文件夹里，换成同名文件即可替换：

- `camera.png`：开场的相机（透明背景的 PNG，正面照）。立体相机的机身轮廓（`js/camera-shape.js`）和镜头前端（`camera-lens.jpg`）都是从这张图生成的，换相机照片时需要一起重新生成。
- `book-cover.jpg`：册子封面（竖版，约 880×1200）。
- `desk.jpg`：书桌和背景（横版照片）。开场镜头会对准照片里的桌垫；如果换成自己的照片，需要在 `js/map-scene.js` 开头的 `DESK` 里改一下桌垫中心的像素坐标（`matX`、`matY`）和宽度（`matW`），合上后的立体效果还要改一下桌面和书架交界的那一行（搜索 805）。

**版权提醒**：目前这三张图分别来自 Sony 产品图和两位小红书用户（@momo、@橘子手作）的照片，署名已写在最后一页。课堂上本地展示问题不大；如果要公开发布到 GitHub Pages，建议先征得原作者同意，或换成自己拍的照片。

## 照片保存在哪里

- 木马上的相片和地图上的地点、照片、底图都保存在**当前浏览器**的本地存储（IndexedDB）中，不会上传到任何服务器。
- 换一台电脑、换一个浏览器，或者清除网站数据后，就看不到之前放的照片了。请保留原图。
- 把链接发给学生，他们看到的是空白的版本，每个人的浏览器各自保存各自的照片。课堂展示建议在讲台电脑上提前放好照片。
- 支持 JPG、PNG、WebP。iPhone 的 HEIC 照片请先导出为 JPG（多数手机浏览器上传时会自动转换）。

## 目录

- `js/carousel-*.js`、`js/memory-projections.js`：旋转木马 3D 场景（由原作 TypeScript 转写）。
- `js/app.js`：首页交互。
- `js/map-*.js`：地图页（手绘底图、3D 沙盘、交互、本地存储）；`js/camera-bag.js`：相机包；`js/desk-props.js`：书桌上的小摆件；`js/camera-model.js`：立体相机。
- `js/grove-app.js`、`js/elephant-diaries.js`、`js/diary-scenes.js`、`css/grove.css`：小象页（绕树走路的小象、日记、风景图、去手账页的字条）。
- `qianfu.html`、`js/qianfu-app.js`、`js/qianfu-data.js`、`css/qianfu.css`：潜伏手账页（手账本、大图与人物说明）；`js/study-gl.js`：这一页的三维书房、书桌和台灯。
- `js/boot.js`：加载 Three.js 的启动脚本。
- `js/shell.js`、`js/lyrics.js`、`js/music-storage.js`、`css/music.css`：外壳页、播放器与动态歌词。
- `css/`：样式与字体声明；`assets/`：贴图、标题图和字体文件。
